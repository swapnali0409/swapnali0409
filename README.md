## 👋 About Me

I'm **Swapnali Rathod**, an Electronics and Telecommunication Engineering student at **Pune Institute of Computer Technology (PICT), Pune**, with a strong interest in **Embedded Systems, Firmware Development and Real-Time Systems**.

I enjoy understanding how hardware and software work together — from configuring microcontroller peripherals and writing firmware to debugging communication and building complete embedded applications.

Currently, I'm focusing on strengthening my skills in **STM32, Embedded C, RTOS, peripheral programming, communication protocols and firmware development**.

**Key Features**

- Multi-channel analog data acquisition
- ADC-based signal sampling
- DMA for continuous data transfer
- Reduced CPU involvement using DMA
- Interrupt-driven firmware for real-time processing
- Sensor values transmitted through UART
- Designed with real-time embedded processing in mind
