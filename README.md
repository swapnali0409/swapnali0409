### Practical RTOS Projects

#### 🔐 FreeRTOS Mutex

Demonstrates safe access to a shared UART resource using multiple tasks.

**Concept:**

`Task 1 ─┐`

`Task 2 ─┼──> Mutex ──> UART`

`Task 3 ─┘`

The mutex ensures that only one task accesses the shared UART resource at a time.

---

#### 📬 FreeRTOS Message Queue

Demonstrates task-to-task communication using a message queue.

**Concept:**

`Sender Task → Message Queue → Receiver Task → UART`

This project focuses on structured data transfer between independent RTOS tasks.

---

#### 📮 Mailbox / Message Passing

Exploring mailbox-style communication concepts for ARM7 and ARM Cortex-M based systems.

**Focus areas:**

- Inter-task communication
- Producer-consumer model
- Message transfer
- Synchronization
- RTOS communication mechanisms
